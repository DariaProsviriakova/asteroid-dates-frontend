# Asteroid Dates Frontend · Лабораторная 7

React SPA каталога дат сближения астероидов. Гость может открыть плитку и ленту и применить фильтр. После входа наблюдатель может сохранять и публиковать свой черновик, ставить и снимать лайки и удалять собственные даты. Для входа нужна учётная запись, подготовленная на стороне бэкенда.

## GitHub Pages

[Демонстрация](https://dariaprosviriakova.github.io/asteroid-dates-frontend/) использует встроенные mock-данные. Ветка `lab7-responsive-pwa-https` содержит исходники, а корень ветки `gh-pages` — содержимое `dist-pages/` после `npm run build:pages`. В Settings → Pages источником публикации служит `gh-pages` → `/(root)`.

На Android установка доступна в меню Chrome. На iPhone в Safari нажмите «Поделиться» → «На экран Домой». После первого открытия service worker кэширует оболочку, сборку и изображение. Чтобы показать фильтр, установите месяц 5, нажмите «Показать», откройте карточку по фото или названию и вернитесь через вкладку «Плитка». Будут видны тот же месяц и две карточки.

## HTTPS в локальной сети

Подключите MacBook и телефон к одной сети Wi-Fi `192.168.1.0/24`. В настройках Wi-Fi на MacBook проверьте фактический IPv4-адрес. В командах ниже `192.168.1.42` — пример адреса ноутбука.

В каталоге бэкенда при запущенных PostgreSQL, Redis и MinIO:

```bash
npm run infra:up
npm run build
HOST=127.0.0.1 TRUST_PROXY=true USE_MINIO_SEED_ASSETS=true DATE_MEDIA_STORAGE=minio npm start
```

В отдельном терминале, в каталоге фронтенда:

```bash
npm ci
npm run cert:lan -- 192.168.1.42
npm run build:lan
npm run serve:lan
```

Скрипт выпускает локальный удостоверяющий центр и подписывает сертификат сервера с IP-адресом в поле SAN. Vite на Node.js загружает `certificates/cert.crt` и `certificates/cert.key`. Для проверки цепочки на телефоне установите публичный `certificates/ca.crt` как доверенный сертификат CA. На iPhone после установки профиля включите полное доверие в «Настройки» → «Основные» → «Об этом устройстве» → «Доверие сертификатам».

Откройте `https://192.168.1.42:8443/dates` на телефоне, войдите под учётной записью бэкенда и откройте «Плитку», «Ленту» и «Добавление». Параметры прокси, HTTPS-порта и путей к ключам указаны в [образце окружения](.env.example). При смене IP повторите выпуск серверного сертификата и перезапустите прокси.

[Диаграмма развёртывания](docs/lab7-deployment.md). Адаптивная сетка выбирает от одной до трёх колонок по доступной ширине. При выборе числа колонок минимальная ширина карточки составляет 300 px. Если внутри страницы меньше 300 px, одна карточка занимает всю доступную ширину. На экранах 340, 590, 768 и 1280 px получается соответственно 1, 1, 2 и 3 колонки с карточками шириной около 308, 558, 338 и 365 px. Изображения имеют пропорции 1,88:1. В «Добавлении» поля медиа располагаются в два столбца от 768 px. [Стили сетки](src/backend.css)

## Запуск для разработки

Требуется Node.js 22.12 или новее (для бэкенда ЛР4 — Node.js 24).

В репозитории бэкенда ЛР4:

```bash
npm ci
npm run infra:up
npm run build
USE_MINIO_SEED_ASSETS=true DATE_MEDIA_STORAGE=minio npm start
```

Здесь, в репозитории фронтенда:

```bash
npm ci
npm run dev
```

Откройте [плитку](http://127.0.0.1:5173/dates). При остановленном бэкенде плитка и лента в гостевом режиме используют локальные mock-данные. Для создания карточки войдите и откройте «Добавление»: выберите фото и видео при необходимости, укажите название и нажмите «Далее». На втором шаге укажите параметры сближения и нажмите «Опубликовать». Если файлы не выбраны, используются фото и видео по умолчанию.

Прокси Vite направляет `/api` на Nest (`127.0.0.1:3000`), а `/s3/<бакет>/<имя>` — в MinIO (`127.0.0.1:9000`). Адреса можно изменить в `.env.local` по образцу [`.env.example`](.env.example). `USE_MINIO_SEED_ASSETS=true` влияет на начальное заполнение пустой базы. Для статического хостинга нужны те же маршруты на обратном прокси.

## Redux и API

Фронтенд использует девять операций веб-сервиса через Axios:

| Операции | Как вызываются |
| --- | --- |
| `POST /api/users/auth`, `POST /api/users/logout` | Прямые вызовы Axios; компоненты вручную отправляют действия в Redux. |
| `GET /api/dates`, `GET /api/dates/feed`, `GET /api/dates/draft`, `POST /api/dates`, `PUT /api/dates/publish`, `POST /api/dates/{id}/like` | Thunk-функции вызывают шесть методов, сгенерированных из OpenAPI ЛР4. |
| `DELETE /api/dates/{id}` | Thunk вызывает явную обёртку над общим Axios-клиентом. В OpenAPI ЛР4 для ответа есть пример без схемы. |

В `auth.status` хранится число: `0` — гость, `1` — создатель. После успешного входа компонент записывает `1` в Redux. Это режим интерфейса; право удалить конкретную карточку определяет её `isCreator` из ответа API. Признак входа хранится только в памяти Redux и не сохраняется в `localStorage`, `sessionStorage` или cookie. После F5 Redux создаётся заново со значением `0`. HttpOnly cookie `asteroids.sid` с идентификатором Redis-сессии сохраняется браузером до истечения срока действия. Её видно в хранилище браузера (Application → Cookies в Chrome). Прокси не пересылает её для гостевого чтения плитки и ленты. Выход завершает сессию и сбрасывает фильтр. Применённый `maxMonth` хранится в Redux и передаётся на сервер.

Команда генерации использует npm-пакет `swagger-typescript-api` и параметры `swaggerCodegen` из `package.json`. Она генерирует интерфейсы и методы Axios. Исходный снимок OpenAPI хранится в `openapi/asteroid-dates.json`.

```bash
npm run generate-backend-types                                      # из сохранённого OpenAPI
npm run generate-backend-types -- http://127.0.0.1:3000/swagger-json    # из работающего Nest ЛР4
npm test
npm run build
```

[Коллекция Postman](postman/Lab6_Asteroid_Dates.postman_collection.json) проверяет плитку с `isCreator: 1` для своей опубликованной карточки. В локальную переменную `sessionCookie` вставьте `asteroids.sid=<значение cookie>` из хранилища браузера. [Диаграмма прецедентов](docs/lab6-use-cases.svg).
