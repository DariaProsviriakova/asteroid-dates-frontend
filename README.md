# Asteroid Dates Frontend · Лабораторная 6

React SPA каталога дат сближения астероидов. Гость может открыть плитку и ленту, применить фильтр и зарегистрироваться. Наблюдатель после входа может сохранить и опубликовать свой черновик, поставить или снять лайк, удалить собственную дату.

## Запуск

Требуется Node.js 22.12 или новее (для бэкенда ЛР4 — Node.js 24).

В репозитории бэкенда ЛР4:

```bash
npm ci
npm run infra:up
npm run build
USE_MINIO_SEED_ASSETS=true DATE_MEDIA_STORAGE=minio npm start
```

Здесь, в репозитории фронтенда:

```bash
npm ci
npm run dev
```

Откройте [плитку](http://127.0.0.1:5173/dates). При остановленном бэкенде плитка и лента в гостевом режиме используют локальные mock-данные. Для создания карточки зарегистрируйтесь, войдите и откройте «Добавление»: сохраните черновик с обозначением, укажите параметры сближения и опубликуйте его.

Прокси Vite направляет `/api` на Nest (`127.0.0.1:3000`), а `/s3/<бакет>/<имя>` — в MinIO (`127.0.0.1:9000`). Адреса можно изменить в `.env.local` по образцу [`.env.example`](.env.example). `USE_MINIO_SEED_ASSETS=true` влияет на начальное заполнение пустой базы. Для статического хостинга понадобится настроить те же маршруты на обратном прокси.

## Redux и API

- `auth` хранит профиль и режим интерфейса. Вход и выход выполняет ручной Axios; компоненты сами отправляют действия в Redux. После F5 Redux начинает с режима гостя. Cookie `asteroids.sid` остаётся в браузере, но Vite не пересылает её для гостевых чтений плитки и ленты. Выход завершает сессию и сбрасывает фильтр.
- `dates` хранит максимальный месяц, карточки и состояния запросов. `maxMonth` передаётся в GET. Thunk-функции вызывают сгенерированный Axios-клиент; доступность удаления определяет серверный `isCreator`.
- [Коллекция Postman](postman/Lab6_Asteroid_Dates.postman_collection.json) проверяет плитку с `isCreator: 1` для своей опубликованной карточки. В локальную переменную `sessionCookie` вставьте `asteroids.sid=<значение cookie>` из хранилища браузера. [Диаграмма прецедентов](docs/lab6-use-cases.svg).

```bash
npm run generate:api                                          # из сохранённого OpenAPI
npm run generate:api -- http://127.0.0.1:3000/swagger-json        # обновить из Swagger ЛР4
npm test
npm run build
```
